# F7.1 — Interview Prep redesign (match Dashboard + Jobs)

Status: **built 2026-10-25** (owner approved all four defaults). Frontend only — no API or behaviour changes.

## Why

Dashboard and Jobs were restyled after the owner's Stitch designs (eyebrow chip, big header with
stat chips, 16 px cards with soft shadow, icon tiles in card heads, gradient bars, pill tabs,
action rows). The six Interview Prep screens still use the older F7 look: plain headers, flat
cards, browser-style selects and radio lists, text-link history, no icons, no motion. Checked
on the mock app at 1440 px on 2026-10-25.

## Shared pieces (first)

1. Move the Dashboard's card building blocks into `src/components/PageKit.tsx` + `styles/kit.css`:
   `PageHeader` (eyebrow, title, subtitle, right-side chips/actions), `CardHead` (icon tile +
   title + sub), `StatChip`, `ActionRow`, `Segmented` (pill group for tabs and filters),
   `EmptyState`. Dashboard switches to them with **no visible change** (screenshot before/after).
2. Interview nav becomes pill tabs like Jobs, with icons and counts: Practice · Live Copilot
   (lock icon when off) · History (n) · Story bank (drafts badge).
3. Motion: card hover lift, bars that fill on first show, staggered fade-in, skeleton loaders.
   All switched off under `prefers-reduced-motion`. Dark mode through the existing tokens.

## Rules

- Same routes, API calls, socket handling and accessible names (labels, roles, button text) so
  the 22 interview tests keep working; any renamed text gets its test updated in the same commit.
- Phone width (375 px): single column, no horizontal scroll, 44 px tap targets.
- Done = `npm run check` green, browser check on the mock app (desktop, 375 px, dark mode) with
  screenshots of every screen, one commit on `dev` (author Avanish Vishwakarma, no trailers),
  no push until you say.
